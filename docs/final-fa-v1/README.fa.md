# بستهٔ نهایی مشخصات توسعه

نسخهٔ `1.0`، ۴ نوامبر ۲۰۲۶؛ وضعیت: آمادهٔ بررسی و تأیید پیش از توسعه.

برای مطالعهٔ راحت، [نسخهٔ مرورگر](FINAL_SPEC.fa.html) را باز کنید. فایل HTML مستقل است و فونت فارسی را در خود دارد؛ برای خواندن به اینترنت نیاز ندارد. جدول محتوا دسترسی به ۲۷ بخش اصلی را فراهم می‌کند.

[منبع Markdown](FINAL_SPEC.fa.md) همان محتوای کامل را برای ویرایش و استفاده هنگام توسعه نگه می‌دارد.

برای بررسی اولیه، بخش‌های ۱ و ۲ دامنه، بخش ۷ دو فیچر منتخب، بخش ۲۲ ترتیب و برآورد توسعه و بخش ۲۵ تصمیم‌های مورد تأیید را بخوانید. بخش‌های ۱۱ تا ۲۱ مشخصات فنی، داده، قرارداد، API و ۴۲ سناریوی پذیرش را پوشش می‌دهند.

این نسخه قرار است پس از تأیید، مبنای ساخت شود. هیچ اپلیکیشن یا قرارداد جدیدی در این مرحله ساخته نشده است. مستندات پیشین برای تاریخچه باقی می‌مانند.
