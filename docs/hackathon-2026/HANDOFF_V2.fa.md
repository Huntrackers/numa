# تحویل نوما نسخهٔ ۲.۰

نسخهٔ ۲.۰ روی دستگاه فعلی اجرا شده است. این تحویل، محصول محلی روی تست‌نت NEAR است؛ نسخهٔ عمومی مین‌نت یا گواهی امنیت مستقل نیست. رابط سایت انگلیسی و توضیحات تحویل فارسی‌اند.

## شروع بررسی

- برنامهٔ اصلی: [ورود به نوما](http://127.0.0.1:4310/login). ورود با Meteor روی تست‌نت انجام می‌شود و حساب‌های نمونه در این محیط خاموش‌اند.
- مرکز عمومی شواهد: [قرارداد، سیاست اجرا و قیمت زنده](http://127.0.0.1:4310/trust). برای مشاهدهٔ این بخش ورود لازم نیست.
- اجرای مستقل برای بررسی: دستور `npm run judge` دیتابیس موقت می‌سازد و روی پورت ۴۳۱۳ اجرا می‌شود. این محیط شخصیت‌های نمونه دارد و از داده و کلید مجری اصلی استفاده نمی‌کند. در صورت اشغال پورت، متغیر `REVIEW_PORT` را تغییر دهید.
- راه‌اندازی نسخهٔ اصلی در ویندوز: فایل `START_NUMA.cmd`؛ توقف: فایل `STOP_NUMA.cmd`. روشن‌بودن دستگاه، اینترنت و worker برای اجرای زمان‌بندی لازم است.

## چه چیزی اضافه و اصلاح شد؟

| تغییر | رفتار قابل‌بررسی | ارزش برای داور و کاربر |
|---|---|---|
| قیمت زندهٔ NEAR Intents | کاتالوگ واقعی، قیمت با امضای تأییدشدهٔ SDK رسمی، حداقل دریافتی، کارمزد و انقضا | اتصال واقعی به زیرساخت NEAR قابل‌دیدن است؛ هیچ انتقال مین‌نت یا آدرس سپرده ساخته نمی‌شود |
| سیاست مشترک اجرا | بررسی شبکه، قرارداد، متد، سپرده، تازگی مشاهده و code hash در API و worker | مجری با اختیار نامحدود یا کد نامنطبق به ارسال نمی‌رسد |
| مرکز شواهد | مشاهدهٔ finalized، وضعیت زمان‌بند و حسابداری، رسیدهای تاریخی و آزمایش مصنوعی سیاست | بررسی ادعاها از یک مسیر ممکن است؛ قطع RPC با موفقیت ساختگی پنهان نمی‌شود |
| لغو واقعی اختیار ادمین | حذف از فهرست ادمین، درخواست نشست قدیمی را هم رد می‌کند | اختیار ذخیره‌شده پس از تغییر تنظیمات باقی نمی‌ماند |
| محیط بررسی مستقل | نصب پاک و ورود نمونه بدون env، API key یا پرداخت | شخص دیگری می‌تواند رفتار محصول را دوباره بررسی کند |
| کنترل تجربهٔ کاربری | خطای provider، پاسخ دیررس، انقضای قیمت، موبایل و برگشت ادمین | مسیر بررسی شفاف‌تر است و پنل کاربر ناخواسته عوض نمی‌شود |

هستهٔ قبلی حفظ شده است: شرکت، نقش و حقوق روزانه/هفتگی/ماهانه، تغییر گروهی، رزرو و پرداخت زمان‌بندی‌شده، گزارش و دفتر حسابداری، اختیار محدود مجری، مطالبه و برداشت مستقل کارمند و اهداف پس‌انداز. دوازده معیار تازه در [پذیرش نسخهٔ ۲](ACCEPTANCE_V2.fa.md) به ۴۲ معیار سند مصوب افزوده شده‌اند. متن سند مصوب تغییر نکرده است.

## مرز واقعی و شبیه‌سازی

تسویهٔ حقوق و تخصیص پس‌انداز با native testNEAR روی قرارداد واقعی تست‌نت انجام می‌شوند. قیمت‌گیری Intents از بازار واقعی، فقط خواندنی و با `dry:true` ثابت است؛ تسویهٔ کراس‌چین نیست. DCA، سرمایه‌گذاری، سهام، Earn، وام و Flexible Payday در دفتر جداگانهٔ demoUSD شبیه‌سازی‌اند. هیچ سود، قیمت آینده یا وام واقعی تضمین نشده است. آدرس چندشبکه‌ای، اثبات مالکیت یا ماندهٔ واقعی چندشبکه‌ای نیست.

کد قرارداد در این نسخه تغییر نکرده است. مقدار code hash بازبینی‌شده در README و مرکز شواهد آمده است. شواهد تراکنش‌های تست‌نت تاریخی‌اند؛ ویدئوی تازه، حقوق نمونه را با برچسب صریح شبیه‌سازی نشان می‌دهد. امضای انسانی تازهٔ Meteor به‌عنوان انجام‌شده گزارش نشده است.

| نصب پاک | نصب قفل‌شده و build موفق؛ سپس startup، ورود نمونه و دیتابیس مستقل بدون env خصوصی بررسی شد |

| وابستگی‌ها | هشت هشدار low؛ صفر moderate، high و critical طبق گزارش ثبت‌شده |

گزارش ماشین‌خوان: [کنترل کیفیت نسخهٔ ۲](../QA_REPORT_V2.json). گزارش‌های قدیمی نسخهٔ ۱ فقط شواهد تاریخی‌اند. تست‌های مرورگر در برخی مرزهای هویت، امضا و تراکنش از fixture استفاده می‌کنند؛ این تعدادها به‌معنای صدها تراکنش واقعی یا تست انسانی نیستند.

## نتیجهٔ داوری و ثبت

در [ارزیابی داخلی](JUDGING.fa.md)، نسخهٔ قبلی ۶۸٫۵ و نسخهٔ ۲ امتیاز ۷۶ از ۱۰۰ گرفته است. سایت وزن عددی رسمی منتشر نکرده؛ پنج محور با وزن برابر، روش داخلی این بررسی‌اند. سازنده و ارزیاب یک عامل‌اند و نتیجه جای داوری مستقل را نمی‌گیرد. نمرهٔ کامل به‌علت نبود شواهد پذیرش بازار، کاربر واقعی، ممیزی مستقل و عملیات عمومی داده نشده است. بالاترین امتیاز رسمی قابل‌تضمین نیست.

مسیر اصلی پیشنهادی Real-World Money است. مسیر Security نیز با اجرای محدود و سیاست قابل‌آزمایش تناسب دارد. همهٔ ۱۳ prompt بررسی شده‌اند؛ مثال‌های هر مسیر، الزام همگانی نیستند. [تطبیق قواعد](COMPLIANCE.fa.md)، [منابع](SOURCES.fa.md) و [بازبینی امنیت](SECURITY_REVIEW.fa.md) جزئیات را دارند.

برای ثبت رسمی، مخزن عمومی، پست عمومی X همراه ویدئو، اطلاعات واقعی تیم و جایزه، رضایت و submission هنوز تکمیل نشده‌اند. متن پیشنهادی و مراحل در [راهنمای نمایش و ثبت](DEMO_AND_SUBMISSION.fa.md) آماده است. اگر فردی پروژهٔ مستقل دیگری هم ثبت کند، افشای نام آن طبق قواعد لازم است. هیچ نام یا رضایتی حدس زده نشده است.

## تحویل به توسعه‌دهنده

بستهٔ سورس شامل کد، قرارداد، lockfile، مجوزها، README و اسناد است. با Node.js ۲۴، دستورهای `npm ci`، `npm run build` و `npm run judge` اجرا می‌شوند. ویدئو و تصاویر در بستهٔ review kit جدا قرار دارند. کلیدها، نشست‌ها، دیتابیس، env خصوصی، لاگ، node_modules و ابزارهای نصب‌شده داخل بسته‌ها نیستند. برای استقرار مستقل تست‌نت، حساب‌ها و کلید مجری محدود باید جدا توسط مالک ساخته و نگهداری شوند.

دیزاین سیستم در `docs/DESIGN_SYSTEM.md` حفظ و برای مرکز شواهد تکمیل شده است. مهارت‌های NEAR Intents، قرارداد NEAR و بازبینی امنیت برای این کار نصب شدند. هیچ API پولی، سرویس ابری پولی یا دارایی مین‌نت خریداری نشده است. منبع عمومی و رایگان می‌تواند محدود یا قطع شود و دستگاه محلی همچنان هزینهٔ برق و اینترنت دارد.
