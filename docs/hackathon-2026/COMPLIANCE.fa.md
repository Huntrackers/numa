# تطبیق نوما ۲.۰ با هکاتون NEAR

تاریخ بررسی: ۶ نوامبر ۲۰۲۶. این گزارش قواعد صفحهٔ رسمی و راهنمای مسابقه را از مثال‌های پیشنهادی مسیرها جدا می‌کند. نتیجهٔ فنی، نسخهٔ محلی قابل‌بررسی است؛ ثبت رسمی هنوز گیت‌های عمومی و انسانی دارد.

| مسیر | تناسب | تصمیم |

| تز سرمایه‌گذاری | ندارد | تحقیق مستقل سرمایه‌گذاری ساخته نشده است |

| کسب‌وکار خودمختار | جزئی | حقوق خودکار و پیشنهاد محدود داریم؛ فروش، خرید و شرکت کاملاً خودمختار نداریم |
| ازدحام ایجنت | ندارد | بازار هماهنگی چندایجنتی ساخته نشده است |

| اقتصاد ایجنت | جزئی و ضعیف | مجری حقوق با تجارت مستقل ایجنت‌ها متفاوت است |
| پول در دنیای واقعی | قوی‌ترین تناسب | حقوق شرکتی، گزارش، اختیار محدود و هدف پس‌انداز |
| بازی | ندارد | حلقهٔ بازی وجود ندارد |
| توکن غیرمثلی | ندارد | دارایی NFT رفتاری وجود ندارد |

تمام ۱۳ prompt خوانده و تطبیق داده شدند. ویژگی‌های داخل آن‌ها ایدهٔ شروع‌اند. تبدیل مثال‌های بازی و NFT به الزام نوما با Q-011 سازگار نیست. مسیر اصلی پیشنهادی «Real-World Money» و مسیر دوم قابل‌دفاع «Security» است.

## نقش مشخص NEAR

- قرارداد، رزرو حقوق را از موجودی آزاد شرکت جدا و اعتباردهی تکراری را متوقف می‌کند.
- مجری فقط `execute_due` را روی قرارداد مشخص فراخوانی می‌کند؛ مدل کلید و ابزار انتقال ندارد.
- هدف پس‌انداز در همان عملیات اعتبار حقوق رزرو می‌شود؛ این رفتار روی زنجیره است.
- ورود Meteor با NEP-413 هویت را تأیید می‌کند؛ امضای ورود اجازهٔ انتقال نیست.
- قیمت ۱Click با SDK رسمی تأیید می‌شود. بازار واقعی خوانده می‌شود، ولی `dry:true` ثابت است و سپرده یا انتقال ساخته نمی‌شود.
- صفحهٔ `/trust` مشاهدهٔ finalized، رسید تاریخی و مرز شبیه‌سازی را به داور نشان می‌دهد.

## هزینه و اختلاف منابع

هیچ API پولی، سرویس AI ابری یا توکن مین‌نت خریداری نشده است. کتابخانه‌ها، SQLite، RPC عمومی و درخواست dry عمومی استفاده شده‌اند. برق، اینترنت، دیسک و روشن‌ماندن دستگاه همچنان لازم‌اند. رایگان‌بودن قیمت‌گیری به‌معنای اجرای بدون کارمزد سواپ آینده نیست.

راهنمای مسابقه در Q-006 کارمزد بدون JWT را ۰٫۲٪ نوشته، ولی راهنمای جاری Intents عدد دیگری بیان می‌کند. نوما درصد ثابت تبلیغ نمی‌کند؛ appFees واقعی provider و حداقل دریافتی را نمایش می‌دهد. اعتبار احتمالی رایگان NEAR AI شرایط و حساب خودش را می‌خواهد؛ وابستگی قطعی پروژه نشده است.
