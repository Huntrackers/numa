# گزارش انتشار نوما، نسخهٔ ۳

نسخهٔ ۳ روی آدرس محلی `http://127.0.0.1:4310` اجرا شده است. تسویهٔ حقوق و پس‌انداز روی تست‌نت NEAR واقعی است؛ سرمایه‌گذاری، DCA، وام و سناریوهای سود همچنان طبق سند، شبیه‌سازی‌اند. هزینهٔ API یا وجه مین‌نت پرداخت نشده است.

## نتیجهٔ داوری

ارزیابی مستقل این مرحله، امتیاز غیررسمی ۹۵ از ۱۰۰ داده است. نتیجهٔ بالاتر از ۹۹ تأیید نشده و امتیاز رسمی مسابقه تضمین نمی‌شود. وزن عددی رسمی منتشر نشده است؛ روش و کسرهای این داور در [گزارش مستقل](INDEPENDENT_REVIEW_V3.md) روشن آمده‌اند. کاربر فعال، درآمد، SLA، ممیزی مستقل، میزبانی پولی یا مین‌نت مبنای جریمه نبوده‌اند.

پنج امتیازِ داده‌نشده به میزان اطمینان آزمایش مربوط‌اند: دو امتیاز برای نبود یک مسیر تازه با تأیید انسانی Meteor در بازبینی مستقل؛ یک امتیاز برای نبود پروفایل گس WASM در حداکثر ظرفیت؛ یک امتیاز برای هشدارهای کم‌خطر وابستگی‌ها؛ و یک امتیاز برای نبود بررسی دستی کامل با ابزارهای کمکی دسترس‌پذیری. این موارد، پنج باگ اثبات‌شده نیستند.

## شواهد قابل بررسی

| بررسی | نتیجه |
|---|---|
| نصب مستقل از ZIP | موفق؛ npm ci و اجرای مستند بازتولید شد |
| واحد و API | ۲۲۷ موفق، صفر شکست |
| مرورگر | ۴۷ موفق، صفر رد یا اجرای ناپایدار |
| قرارداد بومی | ۲۹ موفق؛ یک آزمون خصوصی جداگانه اجرا شد |
| مسیر HTTP نمونه | ۱۰ بررسی موفق |
| مسیر تازهٔ واقعی تست‌نت | ۱۳ بررسی موفق، شامل حقوق خودکار و برداشت |
| مهاجرت قرارداد | ۶۱ رویداد قبلی و موجودی‌ها حفظ شدند |
| قیمت زندهٔ Intents | امضای ارائه‌دهنده تأیید شد؛ ارسال وجه خاموش است |
| محیط اصلی | نسخهٔ ۳، worker فعال و حسابداری VERIFIED |
| وابستگی‌ها | ۸ هشدار کم‌خطر؛ صفر متوسط، بالا یا بحرانی |

هش سورس آزموده‌شدهٔ مستقل با پروژهٔ نهایی یکسان است. [گزارش QA](QA_REPORT_V3.json)، [گزارش تأیید مستقل اجرا](VERIFICATION_V3.json) و [رسید مهاجرت](CONTRACT_MIGRATION_V3.json) جزئیات را ثبت می‌کنند. خواندن مستقل RPC و قیمت زنده توسط داور هم انجام شده؛ او تراکنش تازه‌ای امضا نکرده است.

## اصلاح‌های اصلی

بازیابی هش اشتباه، جلوگیری از استفادهٔ دوباره از رسید و قفل نتیجهٔ نامعلوم تکمیل شد. شکست قطعیِ فراخوان، برگشت وجه و نتیجهٔ نامعلوم دیگر یک حالت مشترک ندارند. نقش‌ها و تصمیم حقوق در حال امضا با ویرایش پروفایل تداخل نمی‌کنند.

تاریخچه، برداشت‌ها و داده‌های تجاری قرارداد به رکوردهای پایدار جداگانه منتقل شدند. برداشت برای ثبت نتیجه مجبور به نوشتن کل داده‌های افراد نیست. آزمون بزرگِ بومی، ذخیرهٔ نهایی وضعیت و بودجهٔ callback را هم پوشش می‌دهد. استقرار و مهاجرت در یک تراکنش انجام می‌شوند؛ راه‌اندازی قرارداد تازه نیز اتمیک شده است.

خطای `libunwind.dll` در اجرای تست ویندوز با تنظیم خودکار مسیر runtime اصلاح شد و تست بعدی موفق بود. مشکل قالب manifest در ZIP نیز در نصب مستقل پیدا و اصلاح شد. منوی ادمین، فوکوس موبایل، کنتراست، جدول‌ها، تب‌های قابل لینک و پاک‌شدن شواهد کهنه پس از خطا بررسی شدند.

مهارت‌های تازهٔ `web-design-guidelines`، `systematic-debugging` و `verification-before-completion` نصب و استفاده شدند. رابط محصول انگلیسی باقی مانده و سند مصوب تغییر نکرده است.

## حدود تحویل

این ارزیابی جای ممیزی بیرونی یا تضمینِ نبود همهٔ باگ‌ها را نمی‌گیرد. بخش‌های مالی شبیه‌سازی‌شده با اجرای واقعی بازار یکی نیستند. مدل محلی اختیاری در بازبینی مستقل تازه اجرا نشده است.

بسته برای ارسال به داور Codex یا Claude آماده است. بازبینی مستقل این مرحله با عامل Codex انجام شده؛ ادعای اجرای داوری Claude نشده است. مخزن عمومی، پست X، مشخصات و رضایت تیم و ثبت رسمی مسابقه هنوز انجام نشده‌اند.
